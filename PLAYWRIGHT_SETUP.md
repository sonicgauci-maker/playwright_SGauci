# Playwright + TypeScript (Playwright UI)

Scaffold untuk menjalankan Playwright dengan TypeScript dan Playwright Test UI.

Langkah instalasi:

```bash
npm install
npx playwright install
```

Perintah yang tersedia:

```bash
# Jalankan semua test headless
npm test

# Jalankan Playwright Test UI (interactive)
npm run test:ui

# Jalankan dengan browser headed (lihat saat eksekusi)
npm run test:headed

# Buka codegen untuk merekam langkah
npm run codegen
```

Contoh file test berada di `tests/example.spec.ts`.
